# mana3-system

Private monorepo for the MANA³ platform.

## Structure

- `scoring-engine/` — Cloud Run scoring engine (mana3-scoring-engine, europe-west1)
- `data-api/` — Cloud Run data API (mana3-data-api, europe-west1)
- `relational/` — S9/S10/S11 relational intelligence (future)
- `prompts/` — Versioned prompt templates (S4 observation, S7 weekly brief)
- `tests/` — Test suite (future)
